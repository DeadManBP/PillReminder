# Pill Reminder

A personal, no-ads, no-account pill reminder for Android — a Pillo-style
replacement without the subscription.

- Add medications with dose, multiple daily times, and days of week
- Persistent dose alarm notification with **Taken / Snooze 10 min / Skip**
  actions; unacknowledged doses re-nag every 10 minutes (up to 1 hour, then
  logged as missed)
- Taken / skipped / missed history log
- Alarms re-arm automatically after reboot or app update
- Everything stays on-device; no network permission, no account

Built with Kotlin + Jetpack Compose. Signed with the same release key as
Brockville Hub. Releases publish an installable APK via GitHub Actions.
